# marohwp

HWP · HWPX 문서를 **읽고, 고치고, 저장하는** 가벼운 Windows용 워드프로세서입니다.
한글 프로그램이 먹통이 되었을 때 급한 문서 작업을 이어갈 수 있는 대안으로 만들었습니다.

- 설치 파일 하나(`marohwp-Setup-<버전>.exe`)로 설치합니다. 관리자 권한이 필요 없습니다.
- 설치가 끝나면 바탕 화면의 **marohwp** 바로 가기를 두 번 눌러 바로 실행합니다.
- 한글의 기본 연결 프로그램 설정은 건드리지 않습니다. `.hwp` / `.hwpx` 파일을 마우스 오른쪽 단추로 눌러
  **연결 프로그램 → marohwp** 로 열 수 있습니다.

## 설치

1. 이 저장소의 **Actions** 탭에서 가장 최근에 성공한 `build` 실행을 열고, 아래쪽 **Artifacts** 의
   `marohwp-Setup` 을 내려받아 압축을 풉니다. (`v1.0.0` 같은 태그를 올리면 **Releases** 에도 같은 파일이 올라갑니다.)
2. `marohwp-Setup-<버전>.exe` 를 실행합니다.
3. 서명이 없는 프로그램이라 Windows 가 "PC 보호" 창을 띄울 수 있습니다. **추가 정보 → 실행** 을 누르면 설치됩니다.
4. 설치가 끝나면 프로그램이 바로 실행되고, 바탕 화면과 시작 메뉴에 **marohwp** 바로 가기가 생깁니다.

제거는 Windows **설정 → 앱 → 설치된 앱 → marohwp → 제거** 에서 합니다.

## 할 수 있는 일

| 구분 | 내용 |
| --- | --- |
| 파일 | HWP 5.0(`.hwp`), HWPX(`.hwpx`) 열기 · 저장 · 다른 이름으로 저장, HWP ↔ HWPX 형식 바꿔 저장, PDF로 내보내기, 인쇄, 최근 문서, 끌어다 놓아 열기 |
| 편집 | 글 입력(한글 입력기 포함), 되돌리기/다시 실행, 오려 두기·복사·붙이기, 찾기/찾아 바꾸기, 쪽 나누기 |
| 글자 모양 | 글꼴, 크기, 진하게, 기울임, 밑줄, 취소선, 위/아래 첨자, 글자 색, 음영 색, 자간 |
| 문단 모양 | 정렬, 왼쪽/오른쪽 여백, 들여쓰기/내어쓰기, 문단 위/아래 간격, 줄 간격 |
| 표 | 표 만들기, 셀 내용 편집, 줄/칸 추가·삭제, 표 지우기, 셀 배경색 |
| 그림 | PNG · JPG · GIF · BMP 그림 넣기(파일, 붙여넣기, 끌어다 놓기), 크기 조절 |
| 쪽 | 용지 종류/방향, 여백 설정 |
| 보기 | 확대/축소, 폭 맞춤 |

### 원본을 지키는 저장 방식

- **손대지 않은 문단·표·개체는 원본 데이터를 그대로** 다시 씁니다. marohwp 가 화면에 그리지 못하는
  도형·수식·차트·양식 개체 등도 지우지 않는 한 파일에 그대로 남습니다.
- 고친 문단만 새로 만들고, 그 문단의 줄 배치 정보는 비워 둡니다. 한글에서 열면 한글이 다시 계산합니다.
- 저장하기 전에 만든 파일을 스스로 다시 읽어 보고, 문제가 있으면 저장을 중단합니다.
- 기존 파일을 덮어쓸 때는 같은 폴더에 `<파일 이름>.bak` 백업을 한 번 만들어 둡니다.

## 알아 둘 점 (한계)

marohwp 는 한글을 대신하는 완전한 프로그램이 아니라 **급할 때 쓰는 대안**입니다.

- 화면은 쪽으로 나뉘지 않은 **연속 보기**입니다. 줄이 바뀌는 자리와 쪽 수는 한글과 다를 수 있습니다.
  (인쇄와 PDF 내보내기에서는 용지 크기에 맞춰 쪽이 나뉩니다.)
- 도형, 수식, 차트, 글맵시, 양식 개체, 필드 등은 **자리 표시**로만 보이고 편집할 수 없습니다. (저장하면 그대로 보존됩니다.)
- 다단 문서는 한 단으로 이어서 보여 줍니다. 문단 번호/글머리표 자동 번호는 화면에 표시되지 않습니다.
- 글상자·머리말·꼬리말·각주의 글은 고칠 수 있지만, 새로 만들 수는 없습니다.
- 셀 합치기/나누기, 표 테두리 모양 바꾸기, 스타일 편집은 아직 없습니다.
- **형식을 바꿔 저장**(HWP → HWPX 또는 반대)하면 글·글자/문단 모양·표·그림·쪽 설정만 옮겨지고
  각주, 머리말/꼬리말, 도형, 수식, 필드 등은 빠집니다. 무엇이 빠졌는지 저장 후 알려 주며, 원래 파일은 그대로 남습니다.
- 암호가 걸린 문서, 배포용 문서, HWP 3.0 이하의 아주 오래된 문서는 열 수 없습니다.
- 한글에 없는 글꼴은 비슷한 글꼴로 바꿔 보여 줍니다. (한글이 설치된 PC 에서는 함초롬바탕 등 한글 글꼴을 그대로 씁니다.)
- 실제 한글 프로그램으로 열어 보는 검증은 자동화하지 못했습니다. 중요한 문서는 저장 후 한글에서 한 번 확인하세요.

## 단축키

| 기능 | 단축키 |
| --- | --- |
| 새 문서 / 불러오기 / 저장 | `Ctrl+N` / `Ctrl+O` / `Ctrl+S` (`Alt+N` / `Alt+O` / `Alt+S`) |

| 되돌리기 / 다시 실행 | `Ctrl+Z` / `Ctrl+Y` |
| 찾기 / 찾아 바꾸기 | `Ctrl+F` / `Ctrl+H` |
| 진하게 / 기울임 / 밑줄 | `Ctrl+B` / `Ctrl+I` / `Ctrl+U` |
| 글자 모양 / 문단 모양 / 쪽 설정 | `Alt+L` / `Alt+T` / `F7` |

| 표에서 다음·이전 칸 | `Tab` / `Shift+Tab` |
| 확대 / 축소 / 100% | `Ctrl++` / `Ctrl+-` / `Ctrl+0` |

## 개발

Node.js 22 이상이 필요합니다. 실행에 필요한 npm 패키지는 없고, 개발용으로 Electron 과 electron-builder 만 씁니다.

```bash
npm ci
```

```bash
npm start
```

```bash
npm test
```

Windows 설치 파일은 Windows 에서 만듭니다.

```bash
npm run dist
```

결과물은 `dist/marohwp-Setup-<버전>.exe` 입니다. GitHub Actions(`.github/workflows/build.yml`)가 푸시할 때마다
Windows 에서 설치 파일을 만들고, **실제로 설치한 뒤 자체 점검**(새 문서 → 입력 → 표·그림 → HWP/HWPX 저장 → 다시 열기)까지
돌립니다. `v1.2.3` 형태의 태그를 올리면 같은 설치 파일로 GitHub Release 를 만듭니다.

브라우저에서 편집 화면만 띄워 볼 수도 있습니다 (파일 열기/저장은 브라우저의 올리기·내려받기로 대신합니다).

```bash
node tools/serve.mjs 8765
```

Playwright 가 설치된 환경이라면 편집 시나리오 점검(입력, 한글 조합 입력, 서식, 표, 붙여넣기, 찾기/바꾸기, 그림, 저장)을 돌릴 수 있습니다.

```bash
node tools/e2e-edit.cjs
```

### 구조

```
electron/        창, 파일 대화 상자, 설치본 자체 점검 (Electron 주 프로세스 / preload)
src/index.html   화면 뼈대
src/app.js       메뉴 · 도구 모음 · 대화 상자 · 파일 열기/저장
src/editor/      편집기 (화면 그리기, 입력 처리, 서식/표 명령, 실행 취소, 저장 모델 만들기)
src/lib/         파일 엔진 (외부 라이브러리 없이 직접 구현)
  cfb.js  zip.js  xml.js  zlibx.js   컨테이너 · 압축
  hwp/    HWP 5.0 읽기/쓰기          hwpx/   HWPX 읽기/쓰기
  convert.js  형식 변환               templates.js  빈 문서 틀
test/            파일 엔진 단위 테스트
tools/           개발용 도구 (문서 구조 덤프, 시험용 정적 서버, 편집 시나리오 점검)
build/           아이콘, 설치 프로그램 스크립트
```
